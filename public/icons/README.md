# PWA Icons

Letakkan file berikut di folder ini agar PWA dapat diinstal dengan benar:

- `icon-192.png` — 192x192 px (latar belakang hitam, logo putih)
- `icon-512.png` — 512x512 px

Sebagai placeholder, file SVG `icon.svg` disertakan dan dapat dikonversi ke PNG
menggunakan alat seperti `sharp` atau layanan online (mis. realfavicongenerator.net).
